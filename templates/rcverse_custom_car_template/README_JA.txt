================================================================================
  🏎️ RCVERSE - RCカー 自作モデル作成スターターキット (Minecraft 1.21.1)
================================================================================

このキットは、無料の3Dモデリングソフト「Blockbench」を使って自分だけのオリジナルRCカーを作成し、
MODの再ビルドなしでMinecraftの世界へ導入するためのテンプレートパッケージです。

--------------------------------------------------------------------------------
【フォルダ構成】
--------------------------------------------------------------------------------
rcverse_custom_car_template/
  ├── pack.mcmeta                               <-- リソースパック情報 (Format: 34)
  ├── README_JA.txt                             <-- 本ドキュメント (日本語)
  ├── README_EN.txt                             <-- English Guide
  ├── config/
  │   └── microdrone/
  │       └── cars/
  │           └── sample_custom_car.json        <-- 【重要】マシンの性能・指定設定ファイル
  └── assets/
      └── microdrone/
          ├── geo/
          │   └── sample_custom_car.geo.json    <-- 【重要】Blockbenchで開いて編集する3Dモデル
          └── textures/
              └── entity/
                  └── sample_custom_car.png     <-- マシンのテクスチャ画像 (128x128)

--------------------------------------------------------------------------------
【Step 1: Blockbenchでモデルを編集する】
--------------------------------------------------------------------------------
1. Blockbench (https://www.blockbench.net/) をインストールして起動します。
2. 左メニューの「ファイル」>「モデルを開く」から、本キットの
   `assets/microdrone/geo/sample_custom_car.geo.json` を開きます。
3. 画面右上のアウトライナー（ボーンツリー）に、以下の必須ボーンが並んでいます：

   [必須ボーン構成]
   - root             : 原点基点 (変更不要)
     └── chassis      : 車体ルート
         ├── body     : メインボディ (ボンネット、ルーフ、バンパー、スポイラー等)
         │              ※着地時のバウンス振動が連動します
         ├── Glass    : 窓ガラス (半透明描画に対応)
         ├── light    : ヘッドライト・テールライト (夜間発光に対応)
         ├── steer_fl : 左前輪ステアリング軸 (自動で左右操舵)
         │   └── wheel_fl : 左前輪タイヤ (回転アニメーション)
         ├── steer_fr : 右前輪ステアリング軸 (自動で左右操舵)
         │   └── wheel_fr : 右前輪タイヤ (回転アニメーション)
         ├── wheel_rl : 左後輪タイヤ (回転アニメーション)
         └── wheel_rr : 右後輪タイヤ (回転アニメーション)

4. キューブのサイズや位置を自由に変えたり、新しいパーツを `body` ボーンの中に追加してモデリングしてください。
   ※ `steer_fl` や `wheel_fl` などのボーン名や階層（親子関係）は変更しないでください。
5. テクスチャは「ペイント」モードで色を塗るか、PNG画像を外部画像ソフトで直接編集して上書き保存します。
6. 完成したら「ファイル」>「エクスポート」>「GeckoLibモデルをエクスポート」で保存します。

--------------------------------------------------------------------------------
【Step 2: マシンの性能を設定する (JSON)】
--------------------------------------------------------------------------------
`config/microdrone/cars/sample_custom_car.json` をテキストエディタで開いて、お好みの性能に調整します：

{
  "id": "my_car",                                  <-- マシン識別ID (半角小文字・英数字)
  "displayName": "マイスポーツRC",                 <-- ゲーム内の表示名 (日本語OK)
  "model": "microdrone:geo/sample_custom_car.geo.json",  <-- モデルファイルのパス
  "texture": "microdrone:textures/entity/sample_custom_car.png", <-- テクスチャパス
  "animation": "microdrone:animations/rc_car.animation.json",   <-- 標準アニメーション
  "properties": {
    "maxSpeedMultiplier": 1.2,    <-- 最高速度倍率 (1.0=標準, 1.5=高速, 0.8=低速)
    "accelMultiplier": 1.3,       <-- 加速力倍率
    "turnSpeedMultiplier": 1.1,   <-- ステアリング旋回速度
    "gripMultiplier": 1.1,        <-- タイヤのグリップ力 (高いほどドリフトしにくく安定)
    "scale": 1.0,                 <-- 車体の表示倍率 (0.8=小型, 1.5=大型)
    "invertSteer": false,         <-- 操舵の左右反転
    "rollMultiplier": 0.5,        <-- コーナー旋回時の車体ロール傾き (0.0=傾きなし, 1.0=標準)
    "maxRollAngle": 35.0          <-- 最大ロール角度
  }
}

--------------------------------------------------------------------------------
【Step 3: Minecraftへ導入する】
--------------------------------------------------------------------------------
1. 設定ファイルの配置:
   Minecraftの実行フォルダにある `config/microdrone/cars/` フォルダの中に、
   編集した `sample_custom_car.json` (または `my_car.json`) をコピーします。

2. リソースパックの配置:
   本キットのフォルダ全体（`assets` や `pack.mcmeta` が入ったフォルダ）を
   Minecraftの `resourcepacks/` フォルダの中にそのまま入れます（またはZIPに圧縮して投入）。

3. ゲーム内でリソースパックを「有効」にします:
   ゲーム内の「設定」>「リソースパック」から、投入したパックを右側の選択欄に移動して「完了」を押します。

--------------------------------------------------------------------------------
【Step 4: ゲーム内で自作マシンに乗る・出現させる】
--------------------------------------------------------------------------------
方法①: 金床で名前を付ける（一番かんたん！）
- 通常のRCカーを「金床（Anvil）」にセットし、名前を `sample_custom_car` や
  設定した `id` または `displayName` に変更して取り出します。
- 地面に置くと、自作モデル＆性能に一瞬で変身します！

方法②: デカール作業台で切り替える
- ゲーム内で「デカール作業台」を右クリックしてRCカーをセットすると、
  自作マシンがバリエーション一覧に現れ、クリックするだけで切り替えられます。

方法③: コマンドで直接スポーン
- チャット欄で以下を実行します：
  /summon microdrone:rc_car ~ ~ ~ {Variant:"sample_custom_car"}
