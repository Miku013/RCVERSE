# アイコン・テクスチャ作成用テンプレート集

マインクラフトのアイテムアイコンやGUIアイコン、32x32テクスチャ作成に使える各種テンプレート画像です。

---

## 🚗 実装ラジコンモデル（RC 86 / RC Car）ベースのテンプレート

MOD内に実装されている **RCカー（AE86モデル / スポーティRCバギー）** の画像枠・パース・輪郭をそのまま抽出した、オリジナル車体アイコン制作用のテンプレートセットです！

| ファイル名 | 解像度 | 内容・用途 |
| :--- | :--- | :--- |
| **`rc_86_template_outline_32x32.png`** | 32×32 | **線画・枠線のみ（背景透過）**。<br>ボディやタイヤの境界線だけが黒〜濃グレーで残っており、中に好きな色を塗るだけで別カラーや新車種が作れます。 |
| **`rc_86_template_coloring_32x32.png`** | 32×32 | **塗り絵用ベース（白ボディ＋黒タイヤ＋ガラス）**。<br>ペイントソフトのバケツ塗り（塗りつぶしツール）で白部分をクリックするだけで一瞬で好きな色の車に変えられます。 |
| **`rc_86_template_base_32x32.png`** | 32×32 | **実装モデルの実寸ドット絵**。<br>細部の陰影やハイライトの描き込み方を参考にしたり、部分的に描き換えるベースとして使えます。 |
| **`rc_86_template_grid_512x512.png`** | 512×512 | **拡大作業用方眼シート**。<br>お絵描きソフト（アイビス、CLIP STUDIO等）で大きく表示してドットを打ちたい時用。完成後に32×32にニアレストネイバー縮小すれば実寸アイコンになります。 |

> ※ 同様に **`rc_car_template_...`** シリーズ（スポーティRCバギー型枠線）も用意されています。

## 📐 汎用 32x32 キャンバステンプレート

新規アイテムや小物、ブロックアイコンを一から自由に描くための基本シートです。

| ファイル名 | 解像度 | 内容・用途 |
| :--- | :--- | :--- |
| **`template_32x32_blank.png`** | 32×32 | 完全透明の白紙キャンバス |
| **`template_32x32_guide.png`** | 32×32 | セーフゾーン（28×28）・センター十字線・外枠1pxマージン付きガイド下敷き |
| **`template_32x32_grid_512.png`** | 512×512 | 1マス16pxの方眼＋透過市松模様＋センター軸入りの拡大編集シート |
