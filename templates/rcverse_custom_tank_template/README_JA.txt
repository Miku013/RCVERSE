================================================================================
  【RCVERSE】RC戦車 自作モデル作成スターターキット (Minecraft 1.21.1)
================================================================================

このキットは、無料の3Dモデリングソフト「Blockbench」を使って自分だけのオリジナルRC戦車を作成し、
MODの再ビルドなしでMinecraftの世界へ導入するためのテンプレートパッケージです。
砲塔旋回、砲身の上下（俯仰）、射撃時のリアルな砲身後座（リコイルアニメーション）、
履帯・転輪の連動回転、砲口フラッシュや地面の土煙エフェクトに対応しています。

--------------------------------------------------------------------------------
【Step 1: Blockbenchでモデルを編集する】
--------------------------------------------------------------------------------
1. Blockbench (https://www.blockbench.net/) をインストールして起動します。
2. 左メニューの「ファイル」→「モデルを開く」から、本キットの
   `assets/microdrone/geo/sample_custom_tank.geo.json` を開きます。
3. 画面右上のアウトライナー（ボーンツリー）に、以下の必須ボーンが配置されています：

   [必須ボーン構成と役割]
   - root             : 原点基点 (変更不要)
     └── chassis      : 車体ルート
         ├── camera_driver : 運転席カメラ位置 (FPV視点)
         ├── battery_slot  : バッテリー装着スロット
         ├── motor_slot    : モーター装着スロット
         ├── antenna       : アンテナパーツ
         │
         ├── [左履帯・車輪グループ]
         │   ├── track_l     : 左履帯ルート
         │   ├── sprocket_fl : 左前方スプロケット (駆動輪回転)
         │   ├── sprocket_rl : 左後方スプロケット (誘導輪回転)
         │   ├── idler_l     : アイドラーホイール
         │   ├── wheels_l    : 転輪群 (走行時に自動回転)
         │   └── ltop, lbottom, lrear_*, lfront_* : 履帯プレート
         │
         ├── [右履帯・車輪グループ]
         │   ├── track_r     : 右履帯ルート
         │   ├── sprocket_fr : 右前方スプロケット
         │   ├── sprocket_rr : 右後方スプロケット
         │   ├── idler_r     : アイドラーホイール
         │   ├── wheels_r    : 転輪群
         │   └── rtop, rbottom, rrear_*, rfront_* : 履帯プレート
         │
         ├── turret   : 砲塔ルート (操作に連動して左右に360度ヨー旋回)
         │   ├── turretbody    : 砲塔の装甲・キューブ群
         │   ├── hatch         : 天面ハッチ
         │   ├── camera_gunner : 砲手・照準カメラ位置 (砲塔の向きに連動)
         │   └── cannon        : 砲身ルート (上下の俯仰角ピッチに連動)
         │       ├── cannonbody: 防盾・砲身基部装甲
         │       └── recoil    : 【超重要】射撃時の砲身後座ボーン！
         │           │           ※このボーン配下に砲身バレル（筒）のキューブを配置すると、
         │           │             射撃の瞬間に後方へ素早くスライドし、滑らかに復座します。
         │           └── muzzle: 砲口先端基点 (射撃フラッシュ・閃光パーティクルの発生位置)
         │
         └── body     : 車体本体装甲キューブ群

4. 【モデリングのコツ】
   - 既存のキューブを動かしたり、サイズを変更したり、新しいキューブを追加して独自の装甲を作れます。
   - 砲身のバレルキューブは必ず `recoil` ボーンの中に配置してください。
   - 砲口位置（発射炎の発生点）は `muzzle` ボーンのピボット位置で決まります。砲身の先端に合わせてピボットを移動してください。
   - 砲手視点カメラを合わせたい位置に `camera_gunner` のピボットを配置してください。
5. テクスチャは「ペイント」モードで色を塗るか、PNG画像を外部画像ソフトで編集して上書き保存します。
6. 完成したら「ファイル」→「エクスポート」→「GeckoLibモデルをエクスポート」で保存します。

--------------------------------------------------------------------------------
【Step 2: 戦車の性能を設定する (JSON)】
--------------------------------------------------------------------------------
`config/microdrone/tanks/sample_custom_tank.json` をテキストエディタで開き、お好みの性能に調整します：

{
  "id": "my_tank",                                  <-- 戦車識別ID (半角英小文字・数字)
  "displayName": "重戦車タイガー",                     <-- ゲーム内の表示名 (日本語対応)
  "model": "microdrone:geo/sample_custom_tank.geo.json",  <-- モデルファイルのパス
  "texture": "microdrone:textures/entity/sample_custom_tank.png", <-- テクスチャパス
  "animation": "microdrone:animations/rc_tank.animation.json",   <-- 標準アニメーション
  "properties": {
    "maxSpeedMultiplier": 1.0,    <-- 最高速度倍率 (1.0=標準, 0.7=超重戦車, 1.3=快速軽戦車)
    "accelMultiplier": 1.0,       <-- 加速力倍率
    "turnSpeedMultiplier": 1.0,   <-- 旋回速度倍率 (信地旋回・超信地旋回)
    "reloadTicks": 20,            <-- 砲弾の再装填時間 (20 ticks = 1秒, 40 = 2秒)
    "cannonPower": 1.2,           <-- 砲弾初速・威力倍率 (1.0=標準)
    "scale": 1.0,                 <-- 車両の全体スケール倍率 (0.8=小型, 1.5=大型戦車)
    "invertCannonPitch": false,   <-- 砲身上下操作の反転 (true=リバース操作)
    "invertTurretYaw": false,     <-- 砲塔旋回操作の反転
    "recoilDistance": 3.0         <-- 【新機能】砲身の後座ストローク幅 (標準: 3.0, 5.0にすると大迫力)
  }
}

--------------------------------------------------------------------------------
【Step 3: Minecraftに導入して遊ぶ】
--------------------------------------------------------------------------------
方法 A: 通常のリソースパックとして導入 (おすすめ)
1. 作成した `assets` フォルダと `pack.mcmeta` を含むフォルダ（またはzip圧縮したもの）を、
   Minecraftの `.minecraft/resourcepacks/` フォルダに入れます。
2. 作成した `sample_custom_tank.json` を、
   Minecraftの `.minecraft/config/microdrone/tanks/` フォルダに入れます。
3. Minecraftを起動し、「設定」→「リソースパック」からパックを有効化します。

方法 B: ゲーム内での呼び出し・召喚
1. 金床 (Anvil) を使って「RC戦車」アイテムの名前を、設定した `id` または `displayName`
   （例: `my_tank` や `重戦車タイガー`）に変更します。
2. 名前を変更したRC戦車を地面に設置すると、自動的に自作モデルとカスタム性能で出現します！
3. プロポ（送信機）を持って右クリックでペアリングすれば、操縦・砲塔旋回・射撃・FPVカメラをすべて楽しめます！

--------------------------------------------------------------------------------
【トラブルシューティング】
--------------------------------------------------------------------------------
Q: 射撃しても砲身がスライドしない
A: 砲身のキューブが `recoil` ボーンの中に配置されているか確認してください。
   また、`config/microdrone/tanks/<ID>.json` の `recoilDistance` が 0 になっていないか確認してください。

Q: 砲身からではなく車体の中央から弾が出る / 閃光が出る
A: `muzzle` ボーンの位置（ピボット）が砲口の先端に合っているか確認してください。
   `muzzle` は `recoil` の子ボーンとして配置されている必要があります。

Q: 砲塔が回転しない / 砲身が上下しない
A: ボーン名が正確に `turret` および `cannon` になっているか確認してください。
   また、`cannon` の親ボーンが `turret` になっているか確認してください。

Q: モデルが読み込まれずデフォルトの戦車になってしまう
A: `config/microdrone/tanks/<ID>.json` の記述（カンマ抜けや波括弧の閉じ忘れなど）にミスがないか確認してください。
   Minecraft 1.21.1 では、ファイルパスはすべて英小文字（半角）である必要があります。
