DEVELOPMENT ROADMAP

開発ロードマップ & 実装予定

現在の開発進捗、完了した機能、および今後予定しているアップデート目標です。

✅ 達成済みマイルストーン Completed
  • ✔ 4種の路面バリエーション＆タブ設定GUI: 道路マーカーGUIからアスファルト、ダート、アイス、水たまりの4路面を選択可能に。各路面ごとの摩擦・グリップ・エフェクト変化を実装 (v1.0.27)
  • ✔ 5大タイヤパーツ換装システム (Tire Customization): ノーマル、ドリフト、グリップ、オフロード、スパイクの各タイヤを実装。手に持って右クリックで即座に換装でき、路面に合わせた最高の走破性を発揮 (v1.0.27)
  • ✔ 氷上物理演算オーバーホール (Extreme Ice Drift): 摩擦0.995・横滑り追従0.02の極限低摩擦スライド挙動を実装。スパイクタイヤで氷上グリップを確保 (v1.0.27)
  • ✔ 全機体マルチプレイ補間同期 (Snapshot Interpolation): 100ms補間バッファと推測航法により、他プレイヤーや観戦カメラから見てもカクつきゼロの完全滑らかな走行・飛行・スタント同期を実現 (v1.0.11)
  • ✔ 自作モデルID金床連携: 金床で名付けたIDでデカール作業台の3Dモデルが即座に同期・保存される仕組み (v1.0.9)
  • ✔ 全編多言語化オーバーホール: RC工作台、3Dデカール工房、全HUD、チャット通知の完全日英対応 (v1.0.8)
  • ✔ 道路生成マーカー: スプライン補間によるアスファルト道路・バンク・ジャンプ台・360°ループの自動敷設システム
  • ✔ マルチプレイ同期の安定化: 他プレイヤーとのプロポ混線・操作干渉ブロック・ゴースト現象の解消
  • ✔ RCカー詳細チューニング: REAL（可変グリップ・荷重移動）とRACE（標準アシスト）の走行モード切替・車重調整
  • ✔ 新世代RC工作台: レシピカタログ選択＆クラフトスロットへのゴースト素材プレビュー機能
🛠 開発・調整中 In Progress
  • ⚙ コース設営用ギミックの拡充: ゴールゲートやチェックポイントの信号連携・サウンドエフェクトのさらなる強化
  • ⚙ 走行・動作サウンドの微調整: モーター高回転時のピッチ調整、タイヤスキール音や水面走行音のリアリティ向上
  • ⚙ 各種操作ガイド・チュートリアル整備: 初心者プレイヤー向け解説ドキュメントおよび動画リソースの拡充

VERSION HISTORY

全バージョン更新履歴（Changelog）

RCVERSEのリリースから最新版までの変更・改善の歩みです。

v1.0.27 最新リリース (Latest)
🛣️ 4種の路面バリエーション・5大タイヤチューニング・氷上ドリフト物理刷新
  • 道路生成マーカーの路面タイプ選択: アスファルト、ダート/オフロード、アイス/氷上、水たまり（ハイドロ減速・水しぶき）の4種類の路面を自由に設定可能に。
  • 設定画面のタブ切り替えGUI: 「形状・コース設定」と「路面タイプ設定」をタブで直感的に切り替えられる新UIを実装。
  • 氷上物理演算の大幅強化: 氷上特有の極低摩擦（減速摩擦0.995、横滑り追従率0.02）を実装し、慣性のまま真横にスーッと滑るリアルなスリップ・パワースライドを実現。
  • 5種類のコース対応タイヤ＆専用アイコン: ノーマル、ドリフト、グリップ、オフロード、スパイクの各タイヤを実装し、専用ピクセルアートアイコンを追加。
  • ドキュメント＆Webサイトのギャラリー拡充: 4種の路面タイプの実機スクリーンショットを公式WebサイトやREADME、CurseForge説明文に統合。
v1.0.11 Multiplayer Smoothing
🌐 全機種対応マルチプレイヤー Snapshot Interpolation（超滑らか位置同期＆観戦カメラ対応）
  • 他プレイヤー視点や定点カメラから見た際の車両・機体のカクつき（ネットワークジッター）を完全に解消する100ms補間バッファシステムを実装。
  • RCカー、RC戦車、RC飛行機、RCスピードボート、RC潜水艦、マイクロドローンの全6機種すべてに水平展開。
  • GeckoLib 4のレンダラーオフセット分離により、大ジャンプや360°ループ、高速ドリフト中もモデルの座標ブレを防止。
  • LANテストおよび複数クライアント接続環境での高品位な同期安定性を実証。
v1.0.9 Decal Anvil Sync
🎨 3Dデカール工房での自作モデルID金床認識＆タグ自動永続化
  • 金床で名前（カスタム名: 86 や truck など）を付けたアイテムを、ステッカー作業台に直接置いた際にも即座に自作3Dモデルを自動認識・プレビュー表示するように修正。
  • デカール適用時に、アイテム内部（NBT）へ自作モデルの Variant タグを自動保存するように強化。
  • 全6系統のRC乗り物（カー、飛行機、ボート、潜水艦、戦車、ドローン）すべてでシームレスな自作モデル反映を実現。
v1.0.8 Complete Localization
🌐 RC工作台・デカール工房・HUD全編の日英完全多言語化
  • RC工作台GUI（カテゴリタブ、ツールチップ、展示スロット、全27種以上のレシピカタログ項目）を多言語キーに完全移行。
  • 3Dデカール工房GUI（車種別タイトル、スライダーラベル、操作ボタン、各部位プリセット名、操作ガイド）を完全日英対応。
  • レース電光掲示板の右クリックチャット表示、戦車HUDの仰角表示、カメラ通知メッセージを日英ローカライズ。
v1.0.7 Road Tool Localization
🛣 道路生成マーカー設定GUIの多言語化＆UI調整
  • 道路生成マーカーの設定画面（道路・ジャンプ台・360°ループ生成モード、道幅、バンク角、分割数、カーブ制御点）を多言語ファイルに移行。
v1.0.6 Tuning UI Localization
🔧 RCカー物理セッティング・チューニングGUIの多言語化
  • スニーク＋プロポ右クリックで開くセッティング画面（REAL/RACE走行モード、車重プリセット、カウンター角、ドリフト開始角）を多言語対応。
v1.0.5 In-Game HUD Localization
📊 ビークルHUD・プロポ・バッテリー表示の多言語化
  • 飛行機・ドローン・戦車・RCカーの各種HUDオーバーレイ、バッテリー残量ブロック数表示、操縦者ダミー人形のネームプレートを多言語キー化。
v1.0.4 Drone Camera & Dummy Fix
🚁 ドローン操縦時の視点・操縦者ダミー挙動の安定化
  • ドローン操縦終了時にプレイヤー本体とダミー人形の座標が同期ズレを起こす現象を解消し、スムーズな離着陸・搭乗解除を実現。
v1.0.3 Multiplayer Safety Patch
🔒 マルチプレイ環境での操作ロックアウト・干渉不具合の解消
  • 他プレイヤーが操縦中のRCマシンに対して、他人が右クリック操作を奪ったり混線してしまう不具合をブロックし、完全なマルチプレイ安全性を確立。
v1.0.2 Race Display Enhancement
⏱ レース電光掲示板のマルチブロック同期＆計測改善
  • 電光掲示板を横に連結した際の巨大スクリーン化同期処理を最適化し、正確なラップタイム計測と順位リアルタイム表示を強化。
v1.0.1 Workbench GUI v2
🔩 新世代RC工作台（メカニカルフレーム＆ゴースト素材）実装
  • 削り出しチタンフレームの専用GUIを新造。左側レシピラックからアイテムを選ぶと3x3グリッドに素材の半透明シャドーが投影される便利機能を実装。

🎉 RCVERSE 正式初回リリース
