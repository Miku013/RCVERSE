OVERVIEW

RCVERSE（アールシーバース）とは？

マイクラの中に「大人のホビーラジコンの世界」を忠実に再現。 手のひらサイズのマシンをプロポ（送信機）で操作し、陸・海・空すべてを舞台にレースやアクロバット、探査を楽しめます。

🎮

プロポ＆FPV操縦

送信機（プロポ）を持った状態でのリアルタイム遠隔操縦。ワンボタンでマシンの目線（FPVカメラ）に切り替え、まるでドライバーになったような迫力ある視点を楽しめます。

⚡

本格的な物理挙動

サスペンションのストローク、ドリフトの慣性、空力滑空、スクリュー推進など、各ビークルごとに最適化された物理演算を実装。手のひらサイズながら本格的な走行・飛行フィールを体感できます。（※エンジン音等の動作サウンドは今後のアップデートで実装予定）

🛠

カスタム＆ガレージ展示

デカール作業台でボディカラーやオリジナルデカールを変更可能。4段RCラックや10スロットの大型RCショーケースに愛車を飾り、眺めて楽しむこともできます。

LINEUP & CONTROLS

陸・海・空を制覇する 6大RCマシン

現在実装されているマシンと開発中のマシン一覧。各マシンの操作方法もこちらで確認できます。

RCカー（ハチロク等） 🟢 実装済み

本格的なサスペンションとステアリング機構を搭載したドリフトカー。タイトコーナーを白煙を上げて滑らかに滑り抜けます。

  • リアルサスペンション＆ロール・ピッチ挙動
  • ドリフト慣性コントロール
  • デカール＆ボディカラー塗装対応
🕹 基本操作方法
  • W / S アクセル / ブレーキ・バック
  • A / D ステアリング（左右旋回）
  • Shift ドリフト（スライド）

マイクロドローン 🟢 実装済み

4つのローターと青色LEDを備えたクアッドコプター。3次元空間をアクロバティックに飛行し、狭い洞窟や障害物コースを攻略できます。

  • 直感的なホバリング＆3次元操縦
  • FPVカメラ（Cキー）での高速レース
  • バッテリー充電システム対応
🕹 基本操作方法
  • Space / Shift 上昇 / 下降
  • W / S 前進 / 後退（ピッチ傾斜）
  • A / D 左右旋回（ヨー）
  • C FPVカメラ視線切り替え

RC戦車 🟡 開発中

左右独立履帯（クローラー）駆動による超信地旋回が可能。独立砲塔旋回と主砲発射ギミックを搭載したミリタリーRC。

  • 左右クローラー独立駆動（超信地旋回）
  • 砲塔旋回＆主砲発射ギミック
  • 悪路走破性能
🕹 基本操作方法
  • W / S 前進 / 後退
  • A / D 左右独立履帯旋回
  • 右クリック 主砲発射

RC飛行機 🟡 開発中

主翼の揚力とプロペラ推進で大空を駆ける固定翼機。バンク旋回やループ飛行など、ダイナミックな空力飛行が楽しめます。

  • 空力揚力演算と滑空（現在調整中）
  • アクロバット旋回・ロール飛行
  • 広大なマイクラ世界の空中散歩
🕹 基本操作方法
  • W / S ピッチ（機首上げ / 機首下げ）
  • A / D ロール（バンク傾き）
  • Space スロットル出力アップ

RCボート 🟡 開発中

水面を滑るように疾走する高速ボート。水しぶきを上げながら川や海をハイスピードでクルージングできます。

  • 水面滑走＆リアル水流エフェクト
  • 軽快なスラローム旋回
  • 動作音・銃火器ギミック実装中
🕹 基本操作方法
  • W / S スロットル前進 / 後退
  • A / D ラダー舵角（左右旋回）

RC潜水艦 🟡 開発中

バラスト制御による自由な潜航・浮上が可能な探査用潜水艦。サーチライトで薄暗い深海や海底遺跡を安全に探索できます。

  • 潜航・浮上深度コントロール
  • 水中サーチライト＆ソナー
  • 水中推進音・銃火器ギミック実装中
🕹 基本操作方法
  • Space / Shift バラスト浮上 / 潜航
  • W / S 前進 / 後退
  • A / D 左右旋回
CONTROL & WORKSHOP

直感操作とこだわりのカスタマイズ

📡

多機能プロポ（送信機）＆FPVカメラ 🟢 実装済み

プロポを手に持ち、設置したラジコンを右クリックして瞬時にペアリング。 画面左下にはバッテリー残量やスロットル状況がリアルタイム表示され、離れた場所からでも自由自在に操縦できます。 マイクロドローンでは「Cキー」でラジコン視点（FPV）に即時切り替え可能です。（※車載FPVカメラは今後のアップデートで他マシンにも順次対応予定）

🏎️

爽快なドリフト走行＆リアル物理挙動 🟢 実装済み

繊細なスロットルワークとカウンターステアによる本格的なドリフト走行を完全再現。 独立サスペンションの沈み込みや車体のロール・ピッチ、滑走時の白煙エフェクトなど、走る歓びを追求しています。（※スキール音や走行音は今後のアップデートで実装予定）

🎨

デカール作業台でのカラーカスタム 🟢 実装済み

デカール作業台を使えば、愛車のボディカラーを各種染料を使って自由に着色可能。 さらに、オリジナルステッカーやレーシングデカールを車体の好きな位置に貼り付けて、世界に一台だけのカスタムマシンを作り上げられます。

🧩

自作3Dモデル（Blockbench）の導入 🟢 実装済み

Blockbenchで自作した3Dモデル（.geo.json）やテクスチャをそのままModへ導入・差し替え可能。 憧れの実車やアニメの劇中車、完全オリジナルのカスタムボディをモデリングして、自分だけの愛車をマイクラの世界で走らせることができます。 👉 詳しい導入手順・フォルダ階層はこちら

GARAGE, CUSTOM & TRACK

愛車を飾るガレージ・デカール工房・本格サーキット

走らせるだけでなく、デカールでの自由なカスタマイズやコレクション展示、コース設計もこのMODの大きな魅力です。

🏢 4段RCラック & 大型ショーケース 🟢 実装済み

スロットごとにピボットが設定された専用家具。置いたマシンは2Dアイコンではなく、実物の3Dモデル（デカール・カラー維持）として美しく展示されます。

  • 4段RCラック: サイドビュー（真横90度）で愛車をすっきり縦積み展示
  • 10スロット大型ショーケース: 幅3×高さ2のガラス張り。斜め25度の黄金アングルで展示
  • 空手スニーク右クリックでスムーズに取り出し・入れ替え

🎨 デカール工房（リバリーエディター） 🟢 実装済み

3Dモデルを見ながら直感的にステッカー（文字やバイナル）を貼り付けられる専用GUI！愛車を世界に1台だけのカスタム仕様に仕上げられます。

  • 3Dリアルタイムプレビュー: マウスドラッグで視点回転・ズーム・移動
  • 部位別貼り付け: ボンネット、ルーフ、トランク、左右ドアに対応
  • 自由な調整: 位置、サイズ、回転（面内）、横幅比率、UV左右反転
  • デカール適用マシンはラックやショーケースでもそのまま立体反映

🏁 レースコース作成 & ドリフト走行 🟢 実装済み

道路生成マーカーを使えば、始点と終点を置くだけでスムーズな高速アスファルトコースが自動敷設されます。

  • 道路生成マーカー: 始点・終点を指定して滑らかな高速サーキット道路を一括自動生成
  • 本格ドリフト: リアルサスペンションとステアリングカウンターによるテールスライド
  • レース設備: ブーストジャンプ台、縁石、スロープ、カラーコーン、ゴールゲート
CUSTOM MODELS & RESOURCE PACK

自作3Dモデル（Blockbench）導入ガイド

MODの再ビルド不要！リソースパックと設定JSONだけで、自分好みの自作マシンを実ゲーム内へ自由に追加できます。

📁 実プレイ環境のファイル・フォルダ階層図

Minecraftのゲームフォルダ（.minecraft または CurseForge等のModインスタンスフォルダ）に、以下のようにファイルを配置します。

.minecraft/ (またはMod環境のインスタンスフォルダ) ├── config/ │ └── microdrone/ │ └── cars/ │ └── my_machine.json <-- 【Step 1】マシンの性能・モデル指定設定ファイル └── resourcepacks/ └── MyRcPack/ <-- 【Step 2】自作リソースパック（フォルダ） ├── pack.mcmeta <-- リソースパックの定義ファイル └── assets/ └── microdrone/ ├── geo/ │ └── my_machine.geo.json <-- Blockbenchで出力したGeckoLib 3Dモデル └── textures/ └── entity/ └── my_machine.png <-- マシンのテクスチャ画像

【Step 1】設定JSON（config）の作成

config/microdrone/cars/<マシンID>.json を作成し、マシンの表示名・モデル参照パス・走行性能（最高速やドリフト摩擦）を定義します。

{ "id": "my_machine", "displayName": "自作カスタムRC", "model": "microdrone:geo/my_machine.geo.json", "texture": "microdrone:textures/entity/my_machine.png", "animation": "microdrone:animations/rc_car.animation.json", "properties": { "maxSpeed": 1.2, "acceleration": 0.08, "driftFriction": 0.88, "weight": 1.1 } }

【Step 2】リソースパックの作成

resourcepacks/MyRcPack/pack.mcmeta を作成し、モデルとテクスチャを配置後、マイクラの「設定 > リソースパック」で適用します。

{ "pack": { "pack_format": 34, "description": "My Custom RC Cars Pack" } }

※Minecraft 1.21.1のリソースパックフォーマットは 34 です。

【Step 3】Blockbenchのボーン推奨構成

Blockbenchで「GeckoLib Animated Model」として作成・エクスポートする際、以下のボーン名にしておくとゲーム内のステアリングやタイヤ回転が自動連動します。

💡 Blockbench実際の作業画面例: 右側のアウトライナー（ツリー）で turret（砲塔）、track_r（履帯）、body（車体）のようにボーン分けして GeckoLib形式（*.geo.json）でエクスポートします。 🔍 クリックで拡大
ボーン名 役割・自動連動
steer_fl / steer_fr 前輪ステアリング（左右の操舵に連動）
wheel_fl / wheel_fr
wheel_rl / wheel_rr		 車輪回転（走行速度に応じたローリング）
body または chassis 車体本体（加減速のピッチや旋回ロール）
fork_and_handle バイク・自転車用フロントフォーク操舵

※モデルの正面は「北（North / Zマイナス方向）」に合わせて作成してください。

【Step 4】ゲーム内での呼び出し・切り替え

導入した自作マシンは、以下のいずれかの方法でゲーム内に出現させることができます。

① デカール作業台で見た目変更

デカール作業台に通常RCカーをセットすると、configに登録された自作モデルがリストに現れ、ワンクリックで外見・性能を切り替えられます。

② コマンドで直接スポーン

/summon microdrone:rc_car ~ ~ ~ {VariantId:"my_machine"}

③ アイテムとして入手

/give @p microdrone:rc_car{BlockEntityTag:{Variant:"my_machine"}}

💡 自作・バリエーションマシンの実機登場例

🛻 モンスタートラック

自作Blockbenchモデル（truck.geo.json）をリソースパックとして読み込ませたカスタムRCカー。巨大タイヤとピックアップボディで大迫力の走りを実現！

🚲 自転車村人（Bicycle）

2輪バイシクルモデルと村人アニメーション。前輪フォーク操舵（fork_and_handle）とペダル連動によるユニークな走行が楽しめます。

🎖️ Blockbench設計モデル（Panzer）

Blockbenchで設計された pzhtank.geo.json。独立砲塔（turret）や履帯など、複雑なマルチボーン機構もGeckoLibで完全同期！

導入方法・動作環境

以下の対応バージョン・前提Modをご確認の上、導入してください。

1

Minecraft & NeoForge の準備

Minecraft: 1.21.1
Java: Java 21（Minecraft 1.20.5+ の必須ランタイム）
Mod Loader: NeoForge 21.1.x（最新推奨）

2

前提Mod「GeckoLib」の導入（必須）

3Dアニメーションおよびモデル描画のため、GeckoLib 4 (NeoForge 1.21.1対応版) が必須となります。 .minecraft/mods フォルダに配置してください。

3

RCVERSE Mod の配置

本ModのJARファイルを .minecraft/mods フォルダに配置してゲームを起動します。
