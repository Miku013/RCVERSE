OVERVIEW

RCVERSE（アールシーバース）とは？

マイクラの中に「大人のホビーラジコンの世界」を忠実に再現。 手のひらサイズのマシンをプロポ（送信機）で操作し、陸・海・空すべてを舞台にレースやアクロバット、探査を楽しめます。

🎮

プロポ＆FPV操縦

送信機（プロポ）を持った状態でのリアルタイム遠隔操縦。ワンボタンでマシンの目線（FPVカメラ）に切り替え、まるでドライバーになったような迫力ある視点を楽しめます。

⚡

本格的な物理挙動

サスペンションのストローク、ドリフトの慣性、空力滑空、スクリュー推進など、各ビークルごとに最適化された物理演算を実装。手のひらサイズながら本格的な走行・飛行フィールを体感できます。（※エンジン音等の動作サウンドは今後のアップデートで実装予定）

🛠

カスタム＆ガレージ展示

デカール作業台でボディカラーやオリジナルデカールを変更可能。4段RCラックや10スロットの大型RCショーケースに愛車を飾り、眺めて楽しむこともできます。

LINEUP & CONTROLS

陸・海・空を制覇する 6大RCマシン

現在実装されているマシンと開発中のマシン一覧。各マシンの操作方法もこちらで確認できます。

RCカー（ハチロク等） 🟢 実装済み

本格的なサスペンションとステアリング機構を搭載したドリフトカー。タイトコーナーを白煙を上げて滑らかに滑り抜けます。

  • リアルサスペンション＆ロール・ピッチ挙動
  • ドリフト慣性コントロール
  • デカール＆ボディカラー塗装対応
🕹 基本操作方法
  • W / S アクセル / ブレーキ・バック
  • A / D ステアリング（左右旋回）
  • Shift ドリフト（スライド）

マイクロドローン 🟢 実装済み

4つのローターと青色LEDを備えたクアッドコプター。3次元空間をアクロバティックに飛行し、狭い洞窟や障害物コースを攻略できます。

  • 直感的なホバリング＆3次元操縦
  • FPVカメラ（Cキー）での高速レース
  • バッテリー充電システム対応
🕹 基本操作方法
  • Space / Shift 上昇 / 下降
  • W / S 前進 / 後退（ピッチ傾斜）
  • A / D 左右旋回（ヨー）
  • C FPVカメラ視線切り替え

RC戦車 🟡 開発中

左右独立履帯（クローラー）駆動による超信地旋回が可能。独立砲塔旋回と主砲発射ギミックを搭載したミリタリーRC。

  • 左右クローラー独立駆動（超信地旋回）
  • 砲塔旋回＆主砲発射ギミック
  • 悪路走破性能
🕹 基本操作方法
  • W / S 前進 / 後退
  • A / D 左右独立履帯旋回
  • 右クリック 主砲発射

RC飛行機 🟡 開発中

主翼の揚力とプロペラ推進で大空を駆ける固定翼機。バンク旋回やループ飛行など、ダイナミックな空力飛行が楽しめます。

  • 空力揚力演算と滑空（現在調整中）
  • アクロバット旋回・ロール飛行
  • 広大なマイクラ世界の空中散歩
🕹 基本操作方法
  • W / S ピッチ（機首上げ / 機首下げ）
  • A / D ロール（バンク傾き）
  • Space スロットル出力アップ

RCボート 🟡 開発中

水面を滑るように疾走する高速ボート。水しぶきを上げながら川や海をハイスピードでクルージングできます。

  • 水面滑走＆リアル水流エフェクト
  • 軽快なスラローム旋回
  • 動作音・銃火器ギミック実装中
🕹 基本操作方法
  • W / S スロットル前進 / 後退
  • A / D ラダー舵角（左右旋回）

RC潜水艦 🟡 開発中

バラスト制御による自由な潜航・浮上が可能な探査用潜水艦。サーチライトで薄暗い深海や海底遺跡を安全に探索できます。

  • 潜航・浮上深度コントロール
  • 水中サーチライト＆ソナー
  • 水中推進音・銃火器ギミック実装中
🕹 基本操作方法
  • Space / Shift バラスト浮上 / 潜航

CONTROL & WORKSHOP

直感操作とこだわりのカスタマイズ

📡

多機能プロポ（送信機）＆FPVカメラ 🟢 実装済み

プロポを手に持ち、設置したラジコンを右クリックして瞬時にペアリング。 画面左下にはバッテリー残量やスロットル状況がリアルタイム表示され、離れた場所からでも自由自在に操縦できます。 マイクロドローンでは「Cキー」でラジコン視点（FPV）に即時切り替え可能です。（※車載FPVカメラは今後のアップデートで他マシンにも順次対応予定）

🏎️

爽快なドリフト走行＆リアル物理挙動 🟢 実装済み

繊細なスロットルワークとカウンターステアによる本格的なドリフト走行を完全再現。 独立サスペンションの沈み込みや車体のロール・ピッチ、滑走時の白煙エフェクトなど、走る歓びを追求しています。（※スキール音や走行音は今後のアップデートで実装予定）

🎨

デカール作業台でのカラーカスタム 🟢 実装済み

デカール作業台を使えば、愛車のボディカラーを各種染料を使って自由に着色可能。 さらに、オリジナルステッカーやレーシングデカールを車体の好きな位置に貼り付けて、世界に一台だけのカスタムマシンを作り上げられます。

🧩

自作3Dモデル（Blockbench）の導入 🟢 実装済み

Blockbenchで自作した3Dモデル（.geo.json）やテクスチャをそのままModへ導入・差し替え可能。 憧れの実車やアニメの劇中車、完全オリジナルのカスタムボディをモデリングして、自分だけの愛車をマイクラの世界で走らせることができます。 👉 詳しい導入手順・フォルダ階層はこちら

GARAGE, CUSTOM & TRACK

愛車を飾るガレージ・デカール工房・本格サーキット

走らせるだけでなく、デカールでの自由なカスタマイズやコレクション展示、コース設計もこのMODの大きな魅力です。

🏢 4段RCラック & 大型ショーケース 🟢 実装済み

スロットごとにピボットが設定された専用家具。置いたマシンは2Dアイコンではなく、実物の3Dモデル（デカール・カラー維持）として美しく展示されます。

  • 4段RCラック: サイドビュー（真横90度）で愛車をすっきり縦積み展示
  • 10スロット大型ショーケース: 幅3×高さ2のガラス張り。斜め25度の黄金アングルで展示
  • 空手スニーク右クリックでスムーズに取り出し・入れ替え

🎨 デカール工房（リバリーエディター） 🟢 全ビークル対応 (v1.1.1)

3Dモデルを見ながら直感的にステッカー（文字やバイナル）を貼り付けられる専用GUI！RCカー（AE86 / トラック / スポーツカー）をはじめ、飛行機、ボート、潜水艦、戦車（PZ戦車 / デフォルト）、ドローンなどのラジコン全車種に完全対応しています。

  • 表面メッシュ吸着投影（B方式）: 車体ポリゴンへ直接投影し、曲面・段差・傾斜装甲や薄板シュルツェンにもピタッと隙間なく完全密着！
  • 全ビークル＆専用プリセット: 車種に応じた部位プリセット（ボンネット、砲塔、キャビン、主翼等）をワンクリック適用
  • 3D自由ドラッグ＆スライダー調整: 3次元空間での直感的な移動と、ミリ単位の微調整スライダーを両立
  • 投影深度カリング: 奥のパーツや反対側パネルへの裏写り・突き抜け描画を物理的に完全防止
  • F4 診断ログ機能: エディタ内でF4キーまたは画面上部ボタンを押すことで、交差面のボーン・法線・投影状態をリアルタイム出力
  • デカール適用マシンはラックやショーケースでもそのまま立体反映

🏁 レースコース作成 & ドリフト走行 🟢 実装済み

道路生成マーカーを使えば、始点と終点を置くだけでスムーズな高速アスファルトコースが自動敷設されます。

  • 道路生成マーカー: 始点・終点を指定して滑らかな高速サーキット道路を一括自動生成
  • 本格ドリフト: リアルサスペンションとステアリングカウンターによるテールスライド
  • レース設備: ブーストジャンプ台、縁石、スロープ、カラーコーン、ゴールゲート

📸 多彩な車体形状・曲面への吸着デカール投影サンプル

表面メッシュ投影 (B方式) 稼働中

Blockbenchのモデル表面ポリゴンそのものを活用してデカールを投影する新アルゴリズムにより、平坦なドアパネルだけでなく、ボートの鋭いキャビン傾斜、潜水艦の円筒曲面、戦車の前面装甲や段差パーツにも、隙間や歪みなく本物のステッカーのようにピタッと吸着します。

DYNAMIC TRACK SURFACES

🛣️ 4種の路面バリエーション & スプラインサーキット

道路生成マーカーで敷設できる4つの路面タイプ。路面ごとに異なるグリップ・摩擦・滑り特性を持ち、専用タイヤとの組み合わせで無限のレース体験が広がります。

🏎️ 標準サーキット

🏁 アスファルト路面 (Asphalt)

舗装された高速サーキット道路。高いグリップ力と素直な旋回性能を発揮し、スリックタイヤでのタイムアタックやドリフトタイヤでのテールスライドに最適です。

⚙️ 推奨タイヤ: グリップタイヤ / ドリフトタイヤ
🏜️ ラリー & オフロード

🚜 ダート路面 (Dirt)

土や小石が敷かれたオフロードトラック。通常タイヤではホイルスピンが発生しますが、オフロードタイヤ装着で駆動ロスなく加速+35%の走破性を実現します。

⚙️ 推奨タイヤ: オフロードタイヤ (加速+35%)
❄️ 氷上エクストリーム

⛸️ アイス路面 (Ice)

極限の低摩擦（Friction 0.995）を誇る凍結路面。通常タイヤではどこまでも流れる豪快な氷上スライド！スパイクタイヤを履くことで氷を噛みしめ安定走行が可能です。

⚙️ 推奨タイヤ: スパイクタイヤ (氷上グリップ確保)
💧 ウェット & 水しぶき

🌧️ 水たまり路面 (Water Puddle)

雨天や水たまりを模したテクニカル路面。突入時の抵抗やスリップ、ダイナミックな水しぶきエフェクトが発生し、天候変化や難関セクションの演出に最適です。

⚙️ 推奨タイヤ: オフロードタイヤ / ドリフトタイヤ

📁 実プレイ環境のファイル・フォルダ階層図

Minecraftのゲームフォルダ（.minecraft または CurseForge等のModインスタンスフォルダ）に、以下のようにファイルを配置します。

.minecraft/ (またはMod環境のインスタンスフォルダ) ├── config/ │ └── microdrone/ │ ├── cars/ │ │ └── my_car.json <-- 【Step 1】RCカーの性能・モデル指定設定 │ └── tanks/ │ └── my_tank.json <-- 【Step 1】RC戦車の性能・後座幅・威力設定 └── resourcepacks/ └── MyRcPack/ <-- 【Step 2】自作リソースパック（フォルダ） ├── pack.mcmeta <-- リソースパックの定義ファイル └── assets/ └── microdrone/ ├── geo/ │ ├── my_car.geo.json <-- Blockbenchで出力したGeckoLib 3Dモデル │ └── my_tank.geo.json └── textures/ └── entity/ ├── my_car.png <-- マシンのテクスチャ画像 └── my_tank.png └── entity/ └── my_machine.png <-- マシンのテクスチャ画像

【Step 1】設定JSON（config）の作成

config/microdrone/cars/<マシンID>.json を作成し、マシンの表示名・モデル参照パス・走行性能（最高速やドリフト摩擦）を定義します。

{ "id": "my_machine", "displayName": "自作カスタムRC", "model": "microdrone:geo/my_machine.geo.json", "texture": "microdrone:textures/entity/my_machine.png", "animation": "microdrone:animations/rc_car.animation.json", "properties": { "maxSpeed": 1.2, "acceleration": 0.08, "driftFriction": 0.88, "weight": 1.1 } }

【Step 2】リソースパックの作成

resourcepacks/MyRcPack/pack.mcmeta を作成し、モデルとテクスチャを配置後、マイクラの「設定 > リソースパック」で適用します。

{ "pack": { "pack_format": 34, "description": "My Custom RC Cars Pack" } }

※Minecraft 1.21.1のリソースパックフォーマットは 34 です。

【Step 3】Blockbenchのボーン推奨構成

Blockbenchで「GeckoLib Animated Model」として作成・エクスポートする際、以下のボーン名にしておくとゲーム内のステアリングやタイヤ回転が自動連動します。

💡 Blockbench実際の作業画面例: 右側のアウトライナー（ツリー）で turret（砲塔）、track_r（履帯）、body（車体）のようにボーン分けして GeckoLib形式（*.geo.json）でエクスポートします。 🔍 クリックで拡大
ボーン名 役割・自動連動
steer_fl / steer_fr 前輪ステアリング（左右の操舵に連動）
wheel_fl / wheel_fr
wheel_rl / wheel_rr		 車輪回転（走行速度に応じたローリング）
body または chassis 車体本体（加減速のピッチや旋回ロール）
fork_and_handle バイク・自転車用フロントフォーク操舵
💥 RC戦車専用ボーン
turret 砲塔ルート（照準に合わせて360度ヨー旋回）
cannon 砲身俯仰軸（砲身の上下ピッチ角度に連動）
recoil 【重要】射撃後座ボーン（配下の砲身バレルが射撃時に後退スライド）
muzzle 砲口先端基点（砲弾および発射閃光・土煙の発生位置）
camera_gunner 砲手視点カメラ位置（砲塔旋回に連動するFPV照準視点）
track_l / track_r
sprocket_* / wheels_*		 左右履帯・スプロケット駆動輪・転輪群（走行・超信地旋回連動）

※モデルの正面は「北（North / Zマイナス方向）」に合わせて作成してください。

【Step 4】ゲーム内での呼び出し・切り替え

導入した自作マシンは、以下のいずれかの方法でゲーム内に出現させることができます。

✨ ① 金床（Anvil）で名前を変更（最も手軽！）

通常のRCカーやRC戦車を金床に入れ、名前を sample_custom_car や sample_custom_tank、設定した id / 表示名に変更して地面に置くだけで、自作モデル＆性能に一瞬で切り替わります！

② デカール作業台で見た目変更

デカール作業台に通常RCカーをセットすると、configに登録された自作モデルがリストに現れ、ワンクリックで外見・性能を切り替えられます。

③ コマンドで直接スポーン

/summon microdrone:rc_car ~ ~ ~ {Variant:"sample_custom_car"}

プロジェクト発足からの歩みとアップデート履歴

v1.1.1 Latest Release 2026-11-24
  • 全車種＆村人の自転車 デカールシステム完全対応: RCカー（86・トラック含む）、飛行機、ボート、潜水艇、戦車、ドローン、そして「村人の自転車」まで、全機体の車体表面メッシュ投影（B方式）に対応！
  • 曲面・段差・傾斜装甲へのピタッと吸着貼り付け: モデル表面ポリゴンを活用し、潜水艦の円筒曲面やボートの傾斜面、戦車の薄板シュルツェン等にも隙間やめり込みなく完全密着。
  • 投影深度カリング＆裏写り・二重表示の根絶: 車体反対側や奥のパーツへの突き抜け・裏写りを物理的に完全遮蔽。
  • 3D自由ドラッグ＆スライダー微調整の操作性向上: 直感的な3次元ドラッグ移動とスライダーによる微調整を両立。
  • 製品版クリーンアップ: 診断ログ出力コード等を完全にオフにし、快適な製品版リリース水準へ最適化。
v1.0.27 Previous 2026-11-23
  • 道路生成マーカーの路面タイプ選択: アスファルト、ダート/オフロード、アイス/氷上、水たまり（ハイドロ減速・水しぶき）の4種類の路面を自由に設定可能に。
  • 設定画面のタブ切り替えGUI: 「形状・コース設定」と「路面タイプ設定」をタブで直感的に切り替えられる新UIを実装。
  • 氷上物理演算の大幅強化: 氷上特有の極低摩擦（減速摩擦0.995、横滑り追従率0.02）を実装し、慣性のまま真横にスーッと滑るリアルなスリップ・パワースライドを実現。
  • 5種類のコース対応タイヤ＆専用アイコン: ノーマル、ドリフト、グリップ、オフロード、スパイクの各タイヤを実装し、専用ピクセルアートアイコンを追加。
  • ドキュメント＆Webサイトのギャラリー拡充: 4種の路面タイプ（アスファルト・ダート・アイス・水たまり）の実機スクリーンショットを公式WebサイトやREADME、CurseForge説明文に統合。
v0.5.0-beta Previous 2026-11-14
  • 10スロット大型RCショーケース追加: 幅3×高さ2のガラス張り展示ケースを実装。斜め25度の展示アングルに対応。
  • 家具上での3D実体モデル描画: RCラックおよびショーケースに展示した際、2Dアイコンではなく実物のGeckoLib 3Dモデル（デカール・ボディカラー保持）で立体描画されるよう大幅刷新。
  • 4段RCラックの展示向き調整: 棚の突き出しに合わせて、真横（90度）のサイドビュー展示に対応。
  • プロポの2D/3Dモデル分離: インベントリやGUI内では16x16の2Dアイコン、手持ち時はリアルな3Dモデルを両立して描画。
  • 道路生成マーカーの視認性改善: 始点（緑矢印）および終点（チェッカーフラッグ）のアイコンデザインを刷新。
  • 公式Webサイト＆アイテム図鑑の公開: 全マシンの解説、32x32ピクセルアイコン、全アイテム仕様図鑑を公開。
v0.4.0-alpha Phase 5 2026-11-13
  • デカール作業台（3Dリバリー工房）の実装: 染料による着色に対応し、オリジナルデカールの3D配置・保存が可能に。
  • 全ビークルへのデカールシステム共通化: 車・飛行機・ボート・潜水艇・戦車・ドローン全機体にステッカー適用が可能に。
  • RC工作台の追加: マシンや送信機、精密コンポーネントを組み立てる専用の作業台を実装。
v0.3.0-alpha Phase 4 2026-11-09 〜 11-12
  • RCカーのドリフト物理演算: 独立サスペンションのストロークと車体ロール・ピッチ挙動、カウンターステアによる慣性スライドを実装。
  • スプライン曲線による道路自動生成: 始点マーカーと終点マーカーを置くだけで滑らかな高速サーキット道路を自動敷設するシステムを開発。
  • コースギミックの実装: ブーストジャンプ台、縁石、電光掲示板、カラーコーンなどのレース機材を追加。
v0.2.0-alpha Phase 3 2026-11-03 〜 11-08
  • 陸・海・空 6大ビークルへの大拡張: マイクロRCカー（ハチロク等）を皮切りに、マイクロRC戦車、RC飛行機、RCボート、RC潜水艇を連続実装。
  • RC戦車の超信地旋回＆砲塔旋回: 左右独立履帯クローラー駆動と主砲発射ギミックを実装。
  • RC飛行機の空力滑空: 固定翼の揚力計算によるダイナミックなアクロバット飛行を実装。
  • RCボートの水面滑走＆潜水艇の潜航浮上: 水上ハイドロプレーン挙動とバラスト深度制御を実装。
v0.1.5-alpha Phase 2 2026-10-31 〜 11-02
  • ブラシレスモーター換装システム: Tier 1（Std）〜 Tier 4（Race）の4段階モーターを実装。最高速度と加速度のチューニングが可能に。
  • 詳細クラフトコンポーネント: プロペラ、カーボンフレーム、ESC基板、M2精密ねじ、シリコン配線など、リアルなラジコン組み立て素材を追加。
  • 送信機（プロポ）製作素材: アンテナ、外装ケース、ジンバルスティック、制御基板、液晶ディスプレイ部品を追加。
v0.1.0-alpha Phase 1 (Origin) 2026-10-27 〜 10-30
  • プロジェクト発足: マインクラフト内でリアルタイムに手のひらサイズのマシンを遠隔操縦する基本アーキテクチャを確立。
  • プレイヤーアバター分離技術: 操縦時にダミーアーマースタンドを生成し、安全に遠隔操作できるパイロットシステムを開発。
  • 144Hzウルトラスムーズ操縦＆FPV HUD: マウス追従カメラとテレメトリHUD（バッテリー残量・スロットル）を実装。
  • 4段階LiPoバッテリー＆急速充電ステーション: リアルなバッテリー着脱・消耗と、GeckoLibアニメーション連動の充電台を開発。
  • 初代GeckoLib 3Dモデル適用: ドローン本体、送信機プロポ、バッテリー、充電器の3Dモデルをゲーム内へ完全統合。

導入方法・動作環境

以下の対応バージョン・前提Modをご確認の上、導入してください。

1

Minecraft & NeoForge の準備

Minecraft: 1.21.1
Java: Java 21（Minecraft 1.20.5+ の必須ランタイム）
Mod Loader: NeoForge 21.1.x（最新推奨）

2

前提Mod「GeckoLib」の導入（必須）

3Dアニメーションおよびモデル描画のため、GeckoLib 4 (NeoForge 1.21.1対応版) が必須となります。 .minecraft/mods フォルダに配置してください。

3

RCVERSE Mod の配置

本ModのJARファイルを .minecraft/mods フォルダに配置してゲームを起動します。
